# Mincer

**Русский** | [English](README_EN.md)

![C++](https://img.shields.io/badge/C%2B%2B-20-00599C?logo=cplusplus)
![SFML](https://img.shields.io/badge/SFML-2.6.x-8CC445)
![Genre](https://img.shields.io/badge/genre-top--down%20shooter-B22222)

Динамичный top-down shooter на SFML. Игрок исследует большие планеты,
уничтожает орды монстров, собирает усиления и проходит пять уровней с
возрастающей сложностью.

## Возможности

- большие процедурно заполняемые игровые области;
- восемь направлений движения персонажа;
- стрельба в сторону курсора;
- магазин, перезарядка и запас патронов;
- несколько типов монстров с разной сложностью;
- бонусы здоровья и боеприпасов;
- масштабирование камеры колёсиком мыши;
- пауза, справка, музыка и звуковые эффекты;
- очки и сохранение рекорда в `gamedata/scores.txt`;
- пять уровней и новый цикл с повышением сложности после победы.

## Управление

| Клавиша | Действие |
|---|---|
| `W`, `A`, `S`, `D` | движение по основным направлениям |
| `Q`, `E`, `Z`, `C` | движение по диагонали |
| `X` | остановиться |
| ЛКМ | выстрелить в сторону курсора |
| ПКМ или `R` | перезарядить оружие |
| колёсико мыши | изменить масштаб камеры |
| `Pause` | пауза |
| `Tab` | показать или скрыть помощь |
| `M` | музыка |
| `Space` | продолжить с экранов уровней и результатов |
| `Esc` | сохранить рекорд и выйти |

## Архитектура

| Компонент | Ответственность |
|---|---|
| `GameEngine` | состояния, ввод, игровой цикл и взаимодействие объектов |
| `Player` | движение, здоровье и ориентация персонажа |
| `Monster` | поведение отдельного противника |
| `MonsterPlanet` | генерация мира и орды |
| `Bullet` | пул и движение снарядов |
| `Pickup` | бонусы здоровья и патронов |
| `Levels` | заставки и переходы между уровнями |
| `GameText` | HUD, помощь и итоговые сообщения |
| `AssetManager`, `GameSound` | ресурсы и звук |

## Сборка через CMake

Требуются CMake 3.21+, Git и компилятор с поддержкой C++20.

```powershell
cmake -S . -B build -DBUILD_SHARED_LIBS=OFF
cmake --build build --config Release
./build/Release/Mincer.exe
```

SFML 2.6.x загружается автоматически. Каталоги `graphics`, `fonts`, `sound`
и `gamedata` копируются к исполняемому файлу.

Для сборки `Mincer.sln` обновите абсолютные пути к SFML в свойствах проекта.
Сохранённая конфигурация Visual Studio ссылается на SFML 2.5.1.

## Статус

Играбельный учебный проект. Возможные улучшения: непрерывное движение при
удержании клавиш, конфигурация управления, сохранение настроек и оптимизация
больших волн противников.
